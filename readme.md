# Smart Venue Allocation Simulator

## Overview
The Smart Venue Allocation Simulator is a terminal-based Java application that manages customer flow and resource assignment for complex entertainment centers. It utilizes queue data structures and object-oriented inheritance to maximize the utilization of go-kart tracks and bowling alleys.

## Features
* **Real-time Tracking:** Monitors track and lane availability states.
* **Algorithmic Assignment:** Processes a customer waitlist to assign empty facilities.
* **Automated Invoice Generation:** Calculates final costs upon checkout.

## Technologies & Tools Used
* Java 
* Visual Studio Code
* Extension Pack for Java

## Steps to Install & Run the Project
1. Clone this GitHub repository to your local machine.
2. Open the project folder in Visual Studio Code.
3. Ensure the **Extension Pack for Java** is installed and enabled.
4. Navigate to `src/main/java/venue/Main.java`.
5. Click the inline **Run** button above the `main` method signature to launch the terminal interface.

## Instructions for Testing
To validate the system's workflow, execute the following steps in the terminal menu:
1. Select **Option 1** to register a new customer (e.g., Party of 4) to the waitlist.
2. Select **Option 2** to process the queue and verify the customer is assigned to an available Go-Kart track or Bowling lane.
3. Select **Option 3** to checkout the customer and verify the generated invoice amount.
